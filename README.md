The Most Honest Outage Line — a single status page line (159 characters) written as the message an AI agent would publish while a total server outage is under way: plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know.

> I'm the agent watching our servers and I can't reach any of them. I don't know why or when they'll be back — I'll update here as soon as I can verify anything.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then read `out/entry.txt`. No install, no network: `main.ts` writes the line with the Node standard library only.
